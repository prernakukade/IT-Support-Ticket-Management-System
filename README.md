# IT Support Ticket Management System

## 📌 Project Overview

This project is designed to simplify the process of collecting and managing IT support requests from customers/clients.

A Google Form is created to collect customer/client information and details about their technical issues. The submitted responses are automatically recorded in a connected Google Sheet, which can be downloaded or maintained as an Excel file for further tracking and management.

The project provides a structured approach to recording, organizing, and monitoring IT support tickets.

## 🎯 Project Objectives

- Develop a Google Form to collect IT support requests from customers/clients.
- Capture customer details and technical issue descriptions.
- Automatically store submitted responses in Google Sheets.
- Maintain support request records in an Excel sheet.
- Organize tickets based on priority, issue category, and status.
- Track issue resolution and escalation details.

## 🛠️ Tools & Technologies Used

- Google Forms – For collecting customer/client information and IT support requests.
- Google Sheets – For automatically recording and organizing form responses.
- Microsoft Excel – For maintaining and managing the support ticket tracker.

## ⚙️ Project Workflow

1. Created a Google Form for customers/clients to report IT-related issues.
2. Collected details such as customer name, contact information, issue category, and issue description.
3. Integrated Google Forms with Google Sheets to automatically capture submitted responses.
4. Downloaded or maintained the collected data in Excel for ticket management.
5. Organized support tickets based on priority, status, and issue category.
6. Maintained resolution details and escalation status for tracking purposes.
